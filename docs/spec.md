# mp2tv 产品规格

术语见 `CONTEXT.md`，选型原因见 `docs/adr/`。

## 1. 范围

做：
- 手机端（Android 10+、iOS 17+）在同一局域网内投屏到电脑端（Windows 10/11 64 位），带声音
- 手机端：扫码配对、已配对设备管理、发起投屏、智能截取、智能旋转、快捷按钮
- 电脑端：托盘常驻、配对二维码、已配对设备管理、自动全屏接收、控制条、窗口模式

不做（v1）：
- 跨网络、USB 有线、会议室访客投屏
- 电脑端反向控制手机
- AirPlay、Miracast、DLNA 接收
- 平板专门适配、画质设置、多语言（只做中文，暂名 mp2tv）

使用前提：个人/家庭；少量长期配对的手机；自用或小范围分发。

## 2. 主要流程

### 配对
1. 电脑端主窗口显示配对二维码（5 分钟有效，用过即刷新）
2. 手机端点"扫码配对"扫描
3. 电脑端提示"已与 XX 配对"，不弹确认框（默认，待确认）；手机端列表出现这台电脑

### 发起投屏
1. 手机端首页点一台在线的电脑（v1 只有这个入口）
2. 系统录屏授权：Android 每次弹授权框；iOS 弹系统录屏选择器
3. 电脑端自动以全屏模式显示画面、播放声音
4. 手机端：Android 自动把媒体音量调到 0；iOS 提示手动调低音量、把"自动锁定"设为"永不"

### 退出投屏
- 任一端退出投屏，两端同时结束；Android 恢复媒体音量；电脑端回到托盘

### 解除配对（默认，待确认）
- 手机端删除电脑：电脑在线时同步删除
- 电脑端删除手机：该手机下次投屏时提示"已被电脑解除配对"

## 3. 手机端

- 首页：已配对电脑列表（名称、在线/离线），可改名、解除配对；"扫码配对"入口
- 快捷按钮（Android 通知栏；iOS 灵动岛和通知中心的实时活动卡片）：强制旋转、智能截取开关（只对本次投屏会话生效）、退出投屏
- 设置：智能截取默认开/关、导出日志
- 投屏期间：
  - 声音：Android 自动把媒体音量调 0，结束后恢复；iOS 开始时提示手动调低
  - 锁屏：尽量不自动锁屏。Android 屏幕超时后只变暗不熄灭，一碰立即恢复亮度；iOS 提示把"自动锁定"设为"永不"。手动按电源键锁屏会结束投屏
  - 断线：自动重连 10 秒，连不上就结束
- 投屏被拒绝时提示原因：电脑离线；电脑正在被 XX 投屏；已被电脑解除配对；电脑已锁屏（默认，待确认）；版本不兼容请升级（默认，待确认）

## 4. 电脑端

- 常驻：开机自启 + 托盘；关闭主窗口回到托盘
- 主窗口：配对二维码、已配对手机列表（可删除）、设置（全屏用的显示器，默认主显示器；开机自启开关；导出日志）；电脑名默认用 Windows 计算机名
- 接收投屏：
  - 已配对手机发起 → 自动以全屏模式显示在设置的显示器上，投屏期间不休眠
  - 已有投屏会话时拒绝其他手机；同一台手机重连可以顶替自己的旧会话
  - 电脑锁屏时拒绝（默认，待确认）
- 控制条：
  - 移动鼠标出现，3 秒不动连同鼠标指针一起隐藏
  - 按钮：退出投屏、旋转、静音（只静音电脑端）、全屏/窗口切换、置顶（窗口模式下）
  - 显示当前投屏的手机名（默认，待确认）
  - 不放智能截取开关
- 键鼠：Esc = 从全屏模式变为窗口模式；双击画面 = 全屏/窗口切换；关闭窗口 = 退出投屏
- 窗口模式：普通窗口，可拖动、缩放，保持画面比例，可置顶
- 断线：显示"连接中断，正在重连"；10 秒内同一台手机重连就继续，否则退出
- 画面显示：保持比例完整显示（竖屏画面左右留黑）；每个投屏会话都从全屏模式开始

## 5. 画面规则

### 智能截取
- 在手机端编码前完成（ADR 0004）
- 只去黑色/接近黑色的边
- 尽量铺满：黑边里零散的字幕、控件不算内容区域，会被切掉
- 暗场（整屏几乎全黑）时保持原来的内容区域
- 内容区域变化要稳定一段时间才切换，避免画面跳动
- 默认开启

### 智能旋转
优先级：跟随旋转 < 重力转正 < 强制旋转。
- 跟随旋转：手机界面转横/竖，电脑端画面跟着变
- 重力转正：同时满足三条才转：① 手机界面是竖屏 ② 手机实际横着拿，稳定 1 秒以上（平放不算）③ 画面里有黑边
- 强制旋转：每按一次顺时针转 90°（90° → 180° → 270°），第 4 次恢复自动；按过之后本次投屏会话不再自动旋转，直到恢复自动；电脑端控制条的旋转按钮和手机端快捷按钮是同一个状态

### 画质与延迟
- 最高 1080p（长边 ≤1920、短边 ≤1080）、60fps，自动调整，不提供画质设置
- 目标延迟 100–200ms（以看视频/短视频为主），音画同步

## 6. 已知限制
- 会员片等有版权保护的视频录屏是黑屏；部分 App 禁止被录音，电脑端没声音
- 投屏时手机的通知、来电界面也会显示在电脑上（Android 15+ 系统会隐藏敏感通知内容）
- 访客网络或路由器开启 AP 隔离时找不到电脑
- 重力转正会误判：手机横放在支架上看带黑边的竖屏视频（用强制旋转纠正）
- iOS 免费开发者账号：App 7 天后要连 Mac 重装、最多 3 台设备；旧路线依赖的 App Groups 能否使用待实测
- Windows 安装包没签名：首次运行有 SmartScreen 提示

## 7. 里程碑与验收

### M1：电脑端 + Android 基础投屏
- 扫码配对成功，手机首页显示电脑在线
- 发起投屏后电脑自动全屏，画面和声音正常；延迟在 100–200ms 量级（测法：手机开秒表，拍一张同时拍到手机和电脑屏幕的照片，读两个读数的差）
- 控制条出现/隐藏正确；退出投屏、静音、全屏/窗口、置顶可用；Esc 和双击行为正确
- 手机转横/竖屏，电脑端画面跟随
- 第二台手机发起投屏被拒绝并有提示；断开 Wi-Fi 后 10 秒内恢复能继续投屏
- 电脑端删除手机后，该手机投屏被拒绝

### M2：Android 完整体验
- 智能截取：竖屏看横屏视频时电脑端铺满；暗场不跳；快捷按钮能临时关闭
- 重力转正：侧躺的内容会被转正；横着拿手机看微信不转
- 强制旋转：循环顺序正确，电脑端旋转按钮同步
- 投屏时手机媒体音量为 0、结束后恢复；屏幕变暗不锁屏、一碰即亮
- 导出日志；解除配对同步
