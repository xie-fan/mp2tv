# mp2tv 测试文档

按版本组织。每个版本先做冒烟（能不能跑通主流程），再逐条过功能点；发现问题记下现象 + 两端日志（见文末"取日志"）。

## 准备

- 电脑和手机连**同一局域网**（访客网络/AP 隔离会找不到电脑）
- 电脑端：装 `mp2tv-x.x.x-portable.exe`（Release 附件，双击即用；首次有 SmartScreen 提示，点"仍要运行"）
- 手机端：`adb install app-debug.apk` 或 Release 附件直接装
- 手机需要的授权：相机（扫码）、麦克风（采集系统声音的前置条件）、通知、录屏（每次投屏弹窗）

## v0.1.0（M1：基础投屏）

### 冒烟

- [ ] 电脑端启动，主窗口显示二维码，托盘有图标
- [ ] 手机端扫码配对成功，首页出现这台电脑、显示"在线"
- [ ] 点电脑名称 → 授权录屏 → 电脑自动全屏显示画面、有声音

### 配对与设备管理

- [ ] 配对成功后二维码刷新（用过的码再扫会失败）
- [ ] 二维码放着 5 分钟不用会自动换新的
- [ ] 手机端长按电脑 → 改名生效
- [ ] 电脑端主窗口能删除手机；删除后该手机再投屏提示已被解除配对
- [ ] 手机端解除配对后，列表里那台电脑消失；若电脑在线，电脑端列表里手机也消失

### 投屏会话

- [ ] 画面流畅，延迟 100–200ms 量级。**测法**：手机打开秒表 App，拍一张同时拍到手机和电脑屏幕的照片，两个读数之差即延迟
- [ ] 手机转横/竖屏，电脑端画面跟随（编码方向跟着变）
- [ ] 声音与画面同步（看视频对口型）

### 控制条与键鼠

- [ ] 移动鼠标底部浮现控制条，3 秒不动自动隐藏（连鼠标指针一起隐）
- [ ] 显示当前投屏的手机名
- [ ] 静音 → 声音停；再点恢复
- [ ] 全屏/窗口按钮切换；窗口模式可拖动、缩放，画面比例不变
- [ ] 窗口模式才有"置顶"按钮；置顶后窗口不被其他窗口盖住
- [ ] Esc = 全屏退到窗口；双击画面 = 全屏/窗口切换
- [ ] 退出投屏 → 两端同时结束，手机通知消失

### 异常路径

- [ ] 第二台已配对手机投屏 → 被拒，提示电脑正被占用
- [ ] 投屏中关掉手机 Wi-Fi → 电脑显示"连接中断，正在重连"；10 秒内恢复 Wi-Fi 能继续；超时会退出
- [ ] 电脑锁屏时手机发起投屏 → 被拒，提示电脑已锁屏
- [ ] 手动按手机电源键锁屏 → 投屏结束

### 常驻行为

- [ ] 关主窗口 → 程序不退、托盘驻留，手机仍可发起投屏
- [ ] 设置里开"开机自启"→ 重启电脑后托盘里有图标

## v0.2.0（M2：Android 完整体验）

### 智能截取

- [ ] **核心场景**：竖屏拿着手机看横屏视频（B 站/抖音全屏前的状态）→ 电脑端只显示视频画面、铺满，没有上下黑边
- [ ] 视频结束回到普通界面 → 电脑端恢复全屏手机画面（区域变化有 ~1 秒延迟属正常防抖）
- [ ] 画面接近全黑时（如视频黑场）→ 截取区域不乱跳
- [ ] 通知栏"截取:开"→ 点一下变"截取:关"→ 电脑端立即变回带黑边的完整画面；只对本次投屏生效，下次投屏按设置里的默认值
- [ ] 设置里关掉"智能截取"→ 新会话默认不截取

### 重力转正

- [ ] 竖屏界面看带黑边的横屏内容、手机横着拿稳 1 秒以上 → 电脑端画面转正成横的
- [ ] 横着拿手机但界面没有黑边（如刷微信）→ 不转
- [ ] 平放在桌面上 → 不转
- [ ] 转回竖着拿 → 画面恢复

### 强制旋转

- [ ] 通知栏"旋转"按钮：按 1 次 90°、2 次 180°、3 次 270°、4 次恢复自动
- [ ] 电脑端控制条"旋转"按钮效果完全一样（同一个状态）
- [ ] 强制旋转期间手机转屏不再自动跟随，直到按到恢复自动

### 音量与亮屏

- [ ] 开始投屏后手机媒体音量自动归零（手机不外放），电脑端正常出声
- [ ] 退出投屏后手机音量恢复到投屏前的值
- [ ] 投屏期间手机屏幕超时后变暗但不熄灭，点一下屏幕立即变亮；不按电源键就不锁屏

### 其他

- [ ] "导出日志"→ 系统"下载"目录出现 mp2tv-log.txt
- [ ] 通知栏三个按钮都在：旋转 / 截取开关 / 停止投屏

## 发现问题时怎么反馈

```
现象：做了什么 → 看到什么（预期是什么）
版本：v0.x.x，手机型号 + Android 版本/ROM，Windows 版本
日志：两端日志文件打包或贴关键行
```

### 取日志

- **电脑端**：`%APPDATA%\mp2tv-windows\logs\mp2tv.log`
- **手机端**：首页"导出日志"按钮 → 下载目录 `mp2tv-log.txt`；或 `adb logcat -s mp2tv`
- 视频类问题附一张手机/电脑同框照片最有用（能看出延迟和画面形态）
